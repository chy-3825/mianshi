      首次使用 · 两步完成

      配置你的面试工作台

      语音默认在本机识别。回答模型可选你自己的兼容接口，或完全在本机运行的 Ollama；两项无需同时配置。

      此选项无需 API Key；请先自行安装 Ollama 并拉取模型。

      仅本地语音模式不会上传录音；若选云端转写，音频会发送到转写服务。回答模型只接收转写文本及你启用的知识库内容。

      Linux 环境检查

      部署自检

      检查运行环境、本地语音模型与回答服务。真实麦克风测试会采集约 3 秒声音，仅用于本次检测；请在安静环境下说一句中文。

      尚未运行自检

      高级设置

      只有选中的服务需要配置。默认使用本地中文语音识别；Deepgram、Gemini 等都是可选项。

      仅用于本地 Qwen3-ASR。自动包含少量技术词和已导入项目的名称、关键词，按长度预算选取；可随时关闭。

      短词表更可靠，不要粘贴 README 或整段描述；关闭后保留补充术语。

      日志仅保存在本机的应用数据目录，可关闭或清空；请勿把日志文件公开分享。

      本地 Qwen3-ASR / SenseVoice 转写不会上传录音。Linux 上采集面试官的声音，请优先选择 PulseAudio/PipeWire Monitor 或已配置的虚拟输入设备；你的麦克风会作为候选人通道。
